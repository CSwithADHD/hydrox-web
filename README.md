# Hydrox Gym — Premium Fitness Landing Page

A premium fitness landing page built with React 18, Vite, TypeScript, Tailwind CSS v4, and Framer Motion.

## Tech Stack

- React 18 + Vite + TypeScript
- Tailwind CSS v4 with `@tailwindcss/vite`
- Framer Motion
- Lucide React Icons
- clsx
- react-intersection-observer

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build

```bash
npm run build
npm run preview
```

## Project Structure

```
src/
  components/
    layout/       Container, Navbar, Footer
    ui/           Button, Badge, SectionTitle, StatsCard, Tabs, Accordion, etc.
    sections/     Hero, FitnessClass, AccordionFeatures, HelpSection, Pricing, etc.
  hooks/          useCountUp, useScrollReveal
  data/           content.ts
  assets/         noise.svg
  App.tsx
  index.css
```
